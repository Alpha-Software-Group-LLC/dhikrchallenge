# Dhikr Challenge

**Remember Allah. Together.**

A private daily practice of remembrance: one authentic dhikr a day for thirty
days, the meaning behind it, and small invite-only Circles of family and friends
who encourage one another.

- `src/content/` — curated, referenced religious content (never generated at runtime)
- `src/data/` — `Backend` interface with Supabase (production) and local guest implementations
- `src/pages/` — Today · Journey · Dhikr · Circles · You
- `supabase/` — baseline schema, additive migration, and a local test harness
- `docs/PRODUCT_MAP.md` — audit, decisions and architecture

See `PRODUCTION_SETUP.md` for deployment.
